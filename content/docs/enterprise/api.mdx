Verified spatial observations become programmatically accessible through the Utopia Enterprise Spatial API. With it you can query an area, push your own observations in, subscribe to a live feed, or check provenance without relying on anyone.

Each pilot receives its own access. Credentials arrive during onboarding, scoped to whichever regions the account is authorized for.

<Callout type="warning">
  The API remains in early access and has no public availability yet. Treat the endpoint URLs, request examples and sample responses throughout the API reference as illustrative. To request access, contact [hello@utopiadata.net](mailto:hello@utopiadata.net).
</Callout>

## Authentication and regions

Bearer API keys control access. Every key is bound to a region and subject to per-account rate limits. Observations from outside a key's region are never returned; a request that reaches across the boundary fails outright instead of being quietly filtered down.

The regions are us-east-1, eu-west-1 and apac-1. Under an enterprise agreement, dedicated residency configurations can be arranged.

## Start with provenance verification

Among the four operations, provenance verification deserves your attention first. The question it settles (is this observation authentic?) is one no vendor's word can settle about its own data. A customer holding the observation and its hash can answer it alone, with no need to trust any other response from Utopia.
